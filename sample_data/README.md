# StatBrief sample data

Demo datasets for the eight demo scenarios (spec AC 52–59). All "IRS" data is invented: IRS
(Institutul Roman de Statistica) is a fictional issuer (D-006), and nothing here is attributed to INS,
Eurostat or the World Bank. The files are generated by `scripts/build_sample_data.py` (fixed seed); the
IRS consumer price figures are derived from the recorded Eurostat HICP responses for Romania in
`tests/data/eurostat/hicp_ro_i15_2021_2024.json` and `hicp_ro_rch_a_2023_2024.json`, so the planted
conflicts are reproducible offline. `tests/unit/test_sample_data.py` checks every property listed below.

### Planted conflicts against Eurostat (IRS Technical Note §3.1–§3.2)

Link the uploaded codes to the public series in the report parameters (links are never inferred):

- `IPC_VAR_AN` → catalog `HICP_YOY` (Eurostat `prc_hicp_minr`, `unit=RCH_A`, geo RO). The IRS national
  rate equals the HICP rate within one rounding unit except in **2023-04, 2023-11 and 2024-07**, where it
  differs by 0.5–0.8 pp (different weights and coverage, §3.1). These three months are value conflicts the
  user must resolve before drafting (prefer one source, keep both labelled, or exclude).
- `IPC` (indice 2021=100, unit `I21`) → the advanced Eurostat series `prc_hicp_minr` with
  `coicop18=TOTAL, unit=I15` (HICP, 2015=100). The IRS index is the HICP rebased to 2021=100 (2021
  average of the recorded series = 115.21), so for March 2024 IRS shows 128.86 while Eurostat shows
  148.44: a gap of about 20 index points caused only by the base year. StatBrief reports all 24 months as
  **unit differences** (`I21` vs `I15`), keeps both values with their sources and never compares,
  averages or gap-fills them, as §3.2 requires.

Deviation from the IRS data dictionary: REG_LUNAR writes the national total as `TOTAL`; the sample writes
`Romania`, which StatBrief's region list resolves to RO (`TOTAL` alone is ambiguous across sources).

## Demo scenarios (AC 52–59)

| AC | Scenario | Use |
|---|---|---|
| 52 | Upload CSV/XLSX and preview | `IRS_regional_monthly_2023-2024.xlsx` (choose sheet Preturi or Somaj), `sector_output_Q.csv` |
| 53 | Map columns and resolve issues | Preturi (exclude the `non_numeric` and `unknown_region` rows, review the duplicate, describe `val_adj_x`); `cryptic_columns.csv` (manual mapping) |
| 54 | Report from uploads only | `sector_output_Q.csv` (QoQ / YoY of quarterly levels), sheet Somaj, `regional_indicators.json` |
| 55 | Report from uploads + API | Preturi `IPC_VAR_AN` linked to `HICP_YOY`, region RO, 2023-01 to 2024-12 (gap filling only with consent) |
| 56 | Trace figures to file/sheet/row or API series | Any figure of scenarios 54–55: sheet + row for the workbook, series id + URL for Eurostat |
| 57 | Detect and resolve conflicts before drafting | Scenario 55 plus the `IPC` link: three value conflicts and 24 base-year unit differences |
| 58 | Resume a paused report with mappings intact | Upload the workbook, save the Preturi mapping, close the browser, reopen the report |
| 59 | Export with citations distinguishing local files from APIs | Approve scenario 55 and download the PDF/XLSX: citations are grouped Uploaded files / Public APIs / Reference documents |
