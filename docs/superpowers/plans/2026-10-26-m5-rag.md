## Task 2 — Loading and splitting (`src/statbrief/rag/loaders.py`)
- `load_reference(path_or_bytes, filename) -> list[Document]` using LangChain loaders: `PyPDFLoader` (page metadata) / `TextLoader`; Markdown via text + `MarkdownHeaderTextSplitter` (section metadata). Metadata on every chunk: `doc_id, title, issuer, owner (None=shared), section, page, source_file`.
- `split_documents(docs, chunk_size, chunk_overlap)` with `RecursiveCharacterTextSplitter`, preserving metadata.
- Reference uploads go through the M2 sniff rules extended for `.pdf/.txt/.md` (size `max_reference_mb`, PDF magic `%PDF-`, no JavaScript/embedded files executed — text extraction only).
- Tests: each format yields chunks with metadata; section/page present; oversize/malformed rejected.

## Task 3 — Store + retrieval (`rag/store.py`, `rag/retriever.py`, migration `004_knowledge_base.sql`)
- `CREATE EXTENSION IF NOT EXISTS vector`; table `kb_chunks(id uuid pk, doc_id, owner uuid NULL FK users cascade, issuer, title, section, page, text, tsv tsvector GENERATED, embedding vector(<dims>) NULL)`; GIN index on tsv; vector index (HNSW cosine) on embedding. Use `langchain-postgres` (`PGVector` or the newer `PGVectorStore` — verify the 0.0.19 API) **if** it can target this table and metadata filter `owner IS NULL OR owner = :user`; otherwise implement a small `VectorStore` subclass over psycopg so it is still a LangChain `VectorStore` (document the choice).
- `index_documents(docs, owner, embeddings, pool) -> int` (idempotent per doc_id/version: re-index replaces).
- `retrieve(query, user_id, k, settings, embeddings|None) -> list[RetrievedPassage(text, doc_id, title, issuer, section, page, score, method)]`: vector search when enabled and embeddings available, else FTS (`websearch_to_tsquery('english', …)`); always user-scoped; deterministic ordering for ties.
- `scripts/index_knowledge_base.py` indexes `knowledge_base/` (shared) — runnable locally against Neon once an OpenAI key exists (M6); FTS rows are written even without a key.
- Tests (pgserver has pgvector): fake embeddings index + vector retrieval returns the HICP regulation for "HICP base year"; FTS fallback returns the NUTS doc for "NUTS 3 Cluj"; user B cannot retrieve user A's uploaded doc; source metadata present for citation.
